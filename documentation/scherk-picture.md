# Doubly periodic Scherk translator picture

The illustration for `ex:catalogue-scherk-translators` replaces the planar boundary diagram with an original numerical construction of the rectangular example. It is an **uncertified finite-boundary PDE approximation with small illustrative corner fills**, not a closed formula or a certified approximation of the complete translator.

## Paper read

Hoffman, Martín and White, *Scherk-like Translators for Mean Curvature Flow*, [arXiv:1903.04617v4](https://arxiv.org/abs/1903.04617v4), dated February 5, 2020:

- Definition 2.1 and Theorem 2.3, pp. 4–6: the parallelogram, the two parameters, and finite base length precisely for `0 < w < pi`.
- Figure 3, p. 6, and Figure 8, p. 10: the rectangular case `alpha = w = pi/2`. The base is longer than the width.
- Theorem 3.1 and its proof, pp. 10–13, Figures 9–10: finite-height boundary curves; adjust the base so the centre has half the boundary height, then translate vertically and let the heights diverge.
- Theorem 5.1, pp. 16–17: `0 < L - w/sin(alpha) < wL/2` and the translator equation.
- Theorem 6.1, pp. 18–19: negative Gauss curvature and the vertical boundary lines.

The paper's velocity is `-e3`. The drawing uses `+e3`, with height reflected and the centre at height zero. Horizontal edges therefore have positive infinite data and the other edges negative infinite data. A half-turn about a **vertical** corner line preserves height. It does not reflect height across an edge. No paper image or source PDF is redistributed.

## Numerical problem

On `(-L/2,L/2) x (-w/2,w/2)`, with `w=pi/2`, solve

```
(1+v_y^2) v_xx - 2 v_x v_y v_xy + (1+v_x^2) v_yy
    = 1+v_x^2+v_y^2.
```

Use `v=+h` on the horizontal edges, `v=-h` on the vertical edges, and `v(0,0)=0`. The unknowns are all interior heights and the base length `L`. The four finite-grid corner values are set to zero; this discretizes a discontinuity, not the full vertical boundary segment. Central second differences, a sparse analytic Jacobian in the heights, a finite-difference column for `L`, and damped Newton iteration solve the finite system. Continuation in `h` and mesh refinement supply the starting guesses. Generation rejects an unconverged solve.

The displayed grid is `257 x 257`, `h=2.5`, `L=2.4482641432`. This is a value for a finite numerical problem, **not** a rigorous decimal for `L(pi/2,pi/2)`.

Here the operator residual is `(delta_ij-v_i v_j/(1+|Dv|^2))v_ij - 1`. The audit region on the **original grid** is `|2x/L| <= 0.8`, `|2y/w| <= 0.8`, `|v| <= 1.5`. It excludes the unresolved corners and steep outer edges. At matched normalized coordinates, refinement from 129 to 257 points changes core heights by at most 0.00596; changing `h=2` to `h=2.5` at 257 points changes them by at most 0.00615. The fourth-order curvature diagnostic is negative throughout this core. These are consistency checks, not error bounds, and are not claims about curvature of the piecewise flat rendering.

## Rendering and limitations

The picture clips to `|z| <= 1.5`. In each quadrant, interpolate horizontal level curves of the computed grid and resample them by arc length. Extend the short unresolved end of each level curve to the exact corner location; this supplies a **small illustrative fill** along the vertical reflection axis. Reflect the four quadrants and weld their common vertices. The fill, level interpolation, and mesh facets are not themselves PDE solutions.

Repeat the patch at rectangle centres `(i L,j w)` with `i-j` even. These are precisely the centres generated by the vertical corner half-turns, since this rectangular patch is centrally symmetric. The patch remains orange and the copies blue. The displayed 13 patches form a finite connected portion; the complete translator repeats indefinitely. Height clipping is a display control, not a geometric parameter. Top view exposes the alternating occupied domains. All top, bottom and exterior edges are artificial display boundaries.

The page retains the existing family properties, routes and tags. No entropy or Gaussian area is inferred from the mesh. The static SVG uses original raster renderings of the same mesh with vector text. The interactive viewer uses WebGL depth testing, supports pointer/keyboard rotation, zoom, mesh display, a fundamental-patch view, top view and height clipping. Without WebGL, or after context loss, the static picture remains available; printing uses it as well.

## Reproduction

```
python3 scripts/generate_scherk_geometry.py
```

Dependencies: NumPy, SciPy, contourpy and Pillow. `scripts/scherk_solver.py` contains the finite-difference solver. The optional `--cache DIRECTORY` uses locally computed NPZ grids; these temporary files are not published. `site/assets/solitons/scherk-audit.json` records the diagnostics. The older author-schematic generator no longer overwrites this picture.
