Example 11.14.8 (An unbounded function at the critical derivative exponent)87FC32996CA8

Example 11.14.8 (An unbounded function at the critical derivative exponent).87FC32996CA8 For every $n\geq 2$ there is an unbounded function in $W^{1,n}_0(B_1\subset \mathbb R^ n)$. In particular, $H_0^1(B_1\subset \mathbb R^2)$ does not embed in $L^\infty $.

Proof

Choose a smooth radial cutoff $\eta $, equal to one on $B_{1/4}$ and zero outside $B_{1/2}$, with $0\leq \eta \leq 1$. For $x\ne 0$ put

\[ u(x)=\eta (x)\log \log (e/|x|), \]

and assign any finite value at zero. This function is unbounded in essential supremum near zero. Its $L^ n$ norm is finite by polar integration. Near zero its gradient has length $1/(r\log (e/r))$, and

\[ \int _0^{1/4}\frac{dr}{r\log (e/r)^ n}<\infty \]

because $n>1$. Integration by parts off $B_\delta $ shows these classical derivatives are weak derivatives: the inner boundary term is bounded by a constant times $\delta ^{n-1}\log \log (e/\delta )$, which tends to zero.

For large $k$, cap the radial logarithmic function at height $k$ before multiplying by $\eta $. The resulting compactly supported functions are Lipschitz, agree with $u$ off a small ball, and converge to $u$ in $W^{1,n}$ by dominated convergence of their values and gradients. Their piecewise gradients are weak gradients because the capped functions are continuous across the matching sphere. Each can be approximated in $W^{1,n}$ by smooth compactly supported mollifications inside $B_1$, using translation continuity in $L^ n$ for the function and its weak derivatives. Hence $u\in W^{1,n}_0(B_1)$. The endpoint failure does not contradict any finite-$q$ assertion in Theorem 11.14.5. $\square$
