Corollary 8.7.3 (Positive width produces a nonzero stationary varifold)CB49E43C32FF

Corollary 8.7.3 (Positive width produces a nonzero stationary varifold).CB49E43C32FF Under the hypotheses of Theorem 8.7.2, if $L>0$, there is a nonzero stationary $n$-varifold on $M$ of mass $L$ in the critical set of the original minimizing sequence.

Proof

The pulled-tight sequence has a nonempty critical set by Lemma 8.5.3. Choose a member. Theorem 8.7.2 makes it stationary and a member of the original critical set; Lemma 8.5.3 gives mass $L>0$. This proof yields neither integrality nor regularity. Those stronger conclusions require additional variational selection, as in the external Theorem 8.2.3. $\square$
