Theorem 7.5.7 (Countable decomposition into embedded smooth manifolds)E0F7CAFA3215

Theorem 7.5.7 (Countable decomposition into embedded smooth manifolds).E0F7CAFA3215 For $1\leq m\leq n$, an $\mathcal H^ m$-measurable $M\subset \mathbb R^ n$ is countably $m$-rectifiable if and only if it is contained, apart from an $\mathcal H^ m$-null set, in a countable union of embedded $m$-dimensional $C^1$ submanifolds. No local finiteness of $\mathcal H^ m\llcorner M$ is required for this equivalence. This is [Sim18], Chapter 3, Lemma 1.2, pp. 85–86.

Proof

First take a Lipschitz parametrization $f:\mathbb R^ m\to \mathbb R^ n$. For each positive integer $i$, Corollary 7.5.6 gives a $C^1$ map $g_ i$ agreeing with $f$ outside a set of measure less than $1/i$. The set $Z$ on which none of the equalities $f=g_ i$ holds has measure zero, since it is contained in each disagreement set. The elementary Hausdorff-measure Lipschitz bound gives $\mathcal H^ m(f(Z))=0$. Thus $f(\mathbb R^ m)$ is covered, apart from that null image, by the images $g_ i(\mathbb R^ m)$.

For a fixed $g_ i$, its critical set $C_ i=\{ \operatorname {rank}Dg_ i<m\} $ has $\mathcal H^ m(g_ i(C_ i))=0$ by the locally proved area formula, Theorem 7.2.2: its Jacobian vanishes, while the multiplicity is at least one on its image. To apply the Lipschitz version of that formula, exhaust the domain by bounded balls on whose closures $Dg_ i$ is bounded, apply it on each ball, and take the countable union of the null critical images. At every point outside $C_ i$, some $m$ coordinate functions have invertible derivative. The inverse function theorem writes the image of a sufficiently small neighborhood as an embedded $C^1$ graph over those coordinates; injectivity follows from that same coordinate inverse. A countable subcover of the open full-rank domain gives countably many such graphs. Apply this argument to every Lipschitz map in Definition 7.1.1, and collect the countably many null sets and charts.

Conversely each embedded $C^1$ manifold has a countable cover by chart images with bounded derivatives on relatively compact base balls. Each graph chart is Lipschitz there and extends coordinatewise to a Lipschitz map on all of $\mathbb R^ m$ by Proposition 7.4.2. The vector extension may increase the constant by the square root of its target dimension, which does not affect countable rectifiability. Add the given exceptional null set. The proof uses Whitney extension, the inverse function theorem and the Euclidean area formula; it does not use the tangent-plane characterization it will help establish. $\square$
