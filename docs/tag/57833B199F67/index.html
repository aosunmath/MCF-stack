Remark 1.1.3 (Scope and illustrations)57833B199F67

Remark 1.1.3 (Scope and illustrations).57833B199F67 The current collection contains 52 example families: 25 shrinkers, 13 translators, 6 expanders, and 8 other special flows. The last category includes stationary solutions, ancient solutions, and other distinguished evolutions. Ancient means defined for all $t<T$ for some finite $T$; eternal means defined for all real times. Neither condition implies that the solution is a soliton.

Explicit formulas are distinguished from implicit equations, ODE constructions, and asymptotic profiles. Every example has a figure. Interactive three-dimensional models allow rotation and zoom; higher-dimensional examples use projections, profiles, or schematics. Captions distinguish exact geometry, numerical ODE approximations, and schematic drawings, and identify truncated noncompact ends. These pictures do not replace the cited existence results. The collection is a growing reference, not an exhaustive classification or a formally verified library.
