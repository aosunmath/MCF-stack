Example 12.4.6 (The same slices can lose detection after reparametrization).EDF55A1658FD Let $\Phi :S^1\to \mathcal Z_ n^0$ be an admissible one-sweepout, with $S^1$ given a finite cubical structure. The family $\Psi (z)=\Phi (z^2)$ has the same image, the same maximal mass and the same small-ball suprema, but is not a one-sweepout.

Proof

The degree-two map $f(z)=z^2$ is surjective, so the sets of slices are identical. On $H^1(S^1;\mathbb Z_2)$ its pullback is multiplication by two, hence zero. Therefore $\Psi ^*\bar\lambda =f^*(\Phi ^*\bar\lambda )=0$. The elementary degree computation can be seen by traversing the oriented circle twice and reducing the resulting homology class modulo two. It shows why covering the same geometric slices does not preserve the topological obstruction. $\square$
