Definition 17.1.1 (The classical scalar obstacle problem)C97A1383B3DD

Definition 17.1.1 (The classical scalar obstacle problem).C97A1383B3DD Let $U\subset \mathbb R^ d$ be bounded with Lipschitz boundary, $f\in L^2(U)$, and $g,\psi \in H^1(U)$. Assume the convex admissible set

\[ K=\{ v\in H^1(U):v-g\in H^1_0(U),\ v\geq \psi \text{ almost everywhere}\} \]

is nonempty. The obstacle problem is to minimize $\mathcal E(v)=\frac12\int _ U|Dv|^2-\int _ Ufv$ over $K$. The inequality is a unilateral constraint. Existence is proved in Theorem 17.2.1; regularity requires additional assumptions.
