Corollary 7.5.6 (Vector-valued agreement on one common good set)7AC9CD6B4783

Corollary 7.5.6 (Vector-valued agreement on one common good set).7AC9CD6B4783 If $f:\mathbb R^ m\to \mathbb R^ n$ is Lipschitz and $\varepsilon >0$, there is $g\in C^1(\mathbb R^ m;\mathbb R^ n)$ such that $f=g$ and $Df=Dg$ outside a set of Lebesgue measure less than $\varepsilon $.

Proof

Apply Theorem 7.5.5 to each of the $n$ scalar components, with exceptional measure less than $\varepsilon /n$. Collect the resulting functions into $g$. Outside the union of their exceptional sets every component and every derivative agrees. Subadditivity gives the claimed measure bound. The common set is essential when using the rank of the vector-valued derivative. $\square$
