Proposition 17.4.4 (Every obstacle blow-up is quadratic homogeneous)55AC4AED0949

Proposition 17.4.4 (Every obstacle blow-up is quadratic homogeneous).55AC4AED0949 Every blow-up $u_0$ in Theorem 17.3.11 satisfies

\[ u_0(tx)=t^2u_0(x)\quad (t>0),\qquad W(s,u_0)=W(0+,u)\quad (s>0). \]
Proof

If $u_{r_ j}\to u_0$ in $C^1_{\mathrm{loc}}$, then for any fixed $s>0$ the bulk and boundary integrals converge, giving $W(s,u_0)=\lim _ jW(s,u_{r_ j})=\lim _ jW(sr_ j,u)=W(0+,u)$. The limit is a normalized obstacle solution, so the equality case on every interval of radii proves global degree-two homogeneity. This uses no classification of homogeneous solutions. $\square$
