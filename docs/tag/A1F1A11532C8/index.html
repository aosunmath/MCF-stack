Example 10.5.4 (A multiplicity jump produces first variation)A1F1A11532C8

Example 10.5.4 (A multiplicity jump produces first variation).A1F1A11532C8 On $P=\mathbb R^ m\times \{ 0\} \subset \mathbb R^{m+1}$, set $\theta =1$ when $x_1<0$ and $\theta =2$ when $x_1>0$. This defines an integral varifold with smooth planar support, but for a compactly supported ambient field $X$,

\[ \delta V(X)=-\int _{P\cap \{ x_1=0\} }X\cdot e_1\, d\mathcal H^{m-1}. \]

Indeed the two half-planes have opposite outward conormals, and their weights leave coefficient $1-2=-1$ on the interface. Thus the varifold is not stationary. Smoothness of support alone does not imply constant multiplicity, and the singular first variation is not represented by a function integrable with respect to the $m$-dimensional weight.
