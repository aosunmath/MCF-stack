Example 2.6.1 (Drugan's immersed shrinking spheres)FE38A115C52C

Example 2.6.1 (Drugan's immersed shrinking spheres).FE38A115C52C For each $n\geq 2$, there is a smooth rotational immersion $X:S^ n\to \mathbb R^{n+1}$ satisfying $\vec H=-X^\perp /2$ whose image is not embedded. The associated immersed flow is $X_ t=\sqrt{-t}\, X$, $-\infty <t<0$. In the three-dimensional construction, a graphical piece of the profile, written as axial height $z=\gamma (r)$ for $r>0$, solves

\[ \frac{\gamma ''}{1+(\gamma ')^2} =\left(\frac r2-\frac1r\right)\gamma '-\frac\gamma 2. \]

This is equation (1.3) of [CatDrugan2015], p. 3140. Shooting and continuation through profile turning points produce the closed immersed sphere; a single graphical piece does not describe the whole surface.

  • The parameter domain is the compact sphere, so the induced metric is complete and the immersion is proper. The image has self-intersections and is not the round sphere.

  • The construction has rotational symmetry and reflection symmetry across a hyperplane perpendicular to the rotation axis. It has no ends. The homothetic flow contracts to the origin with Type I curvature growth.

  • The cited existence argument supplies neither an elementary parametrization nor uniqueness or an exact entropy value. Embedded classification and embedded stability theorems cannot be applied to this immersion by dropping their embeddedness hypothesis.

The numerical profile in [CatDrugan2015], Figure 1, is an illustration of the shooting construction. Our diagram records the domain topology and the distinction between immersion and embedding; it does not solve the shooting problem.
