Definition 6.5.2 (Centered maximal functions)E382FA55D5F1

Definition 6.5.2 (Centered maximal functions).E382FA55D5F1 For a nonnegative Radon measure $\nu $ on $\mathbb R^ n$ define

\[ M\nu (x)=\sup _{r>0}\frac{\nu (B_ r(x))}{\omega _ n r^ n}. \]

For $f\in L^1_{\rm loc}(\mathbb R^ n)$ write $Mf=M(|f|\, dx)$. The value may be infinite. These are measurable functions: for fixed $r$, Fatou's lemma makes $x\mapsto \nu (B_ r(x))$ lower semicontinuous, and the supremum retains this property. This maximal quantity controls the upper density defined in [Sim18], Chapter 1, equation (3.1).
